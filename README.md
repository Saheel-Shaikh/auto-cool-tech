# 🚗 Auto Cool Tech

> **A premium full-stack e-commerce platform built specifically for automotive replacement parts, tools, and accessories.**

![Auto Cool Tech Banner](https://images.unsplash.com/photo-1492144534655-ae79c964c9d7?ixlib=rb-4.0.3&auto=format&fit=crop&w=1000&q=80)

## 🌟 Features
* **Full E-Commerce Flow:** Functional shopping cart, shipping, and checkout process.
* **Product Management:** Search products, categories, user ratings, and review system.
* **User Dashboards:** Dedicated user profiles with complete order history tracking.
* **Admin Panel:** Secure admin control for managing users, adding products, and tracking orders.
* **Modern UI/UX:** Clean, responsive blue-and-white theme designed for optimal user experience.

## 💻 Tech Stack (MERN)
* **Frontend:** React, Redux, React-Bootstrap
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas
* **Authentication:** JSON Web Tokens (JWT)
